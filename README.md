1v1 Online

Project Overview
1v1 Online is a 3D First-Person Shooter (FPS) online multiplayer game designed for two players. The game features a 1v1 Deathmatch mode where players compete against each other in a fast-paced battle.
The objective is to be the first player to reach the predetermined kill limit. Players must use their shooting skills, movement, and strategies to eliminate their opponent and win the match.

Project Information
